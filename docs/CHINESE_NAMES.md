# 中文鳥名：兩套名錄並存

> 一句話：**華文圈沒有「官方」中文鳥名。** 香港觀鳥會與中華民國野鳥學會（台灣）
> 各有自己的名錄，兩邊都是長年通行的叫法。圖鑑做的是「兩邊都搵得到」，
> 不是「只准一個名」。

## 規矩

| 位置 | 用哪個名 | 為什麼 |
|---|---|---|
| 卡面主名（`birds.json` / `cardCopy.json`） | **香港慣用寫法** | 這套卡是給香港野外用的，你拿着卡問人、對書，要對得上本地講法 |
| 搜尋別名（`explorerIndex.json` → `n`） | **台灣鳥類名錄的名** | 你手上可能有台灣出版的圖鑑、或在網上見到台灣叫法；打落去一樣搵得到那隻雀 |
| 卡面副標（中文模式） | 顯示「台灣名錄作 ⋯」 | 讓你知道「這隻雀另一個名」，不用以為自己看錯 |

**台灣名永遠不會覆蓋香港名。** `tests/twNames.test.mjs` 會擋住這件事。

## 為什麼不選邊

「正確的中文名」本身是一個沒有答案的問題：

- 兩地名錄都是各地鳥會長年整理、有編者、有版本、有引用依據的正式出版物
- 同一隻鳥兩地叫法不同，多半是歷史約定俗成，不是誰對誰錯
- 硬要統一，會令拿着另一邊圖鑑的人對不上號，這對野外辨識是**負面**的

所以做法是：**主名保留香港寫法（本地實用），別名收台灣寫法（可達性）**，
兩邊都記下出處。

## 工具

```bash
# 1) 去 https://www.bird.org.tw/download/5698 下載 XLSX（約幾百 KB）
# 2) 對照＋產生別名（只讀事實欄位：中文名／學名／科名／遷徙屬性／保育等級）
npm run cards:tw -- --xlsx "C:\Users\<你>\Downloads\2026 臺灣鳥類名錄 (0820修正).xlsx"

# 只報告、不寫檔
npm run cards:tw:check -- --xlsx "<同上>"

# 3) 把別名併入搜尋索引
npm run cards:explorer
```

輸出：

- `src/data/twNames.json` — 台灣名別名表，含 `_readme`（來源、取得網址、版本、規則）
- `reports/tw-list-diff.md` — 中文名差異清單＋對不上的卡（人手確認用）

## 對照方法（可追溯）

1. **主鍵用學名**，不是中文名（中文名正是我們要比對的東西，不能拿來做鍵）
2. 學名對不上時，退一步用**種小名**，但要有**第二重證據**（同科 或 英文俗名相同）才收貨
   — 因為 `chinensis` 同時是黑枕黃鸝（*Oriolus chinensis*）和珠頸斑鳩
   （*Spilopelia chinensis*）的種小名，只靠種小名會配錯鳥
3. 屬名近年大幅變動（`Charadrius` → `Anarhynchus` 等），靠種小名才能接上；但接上之後
   會在報告裡標明「靠種小名」，讓你知道這筆配對比對弱一些

## 版權

只取**事實欄位**（名稱、學名、科名、遷徙屬性、保育等級）。
台灣名錄的解說文字、圖表一概不搬——一來尊重原編者，二來名錄本身有版權聲明。
香港觀鳥會名錄（`hkbws.org.hk`）同樣是「版權保留，未經書面授權禁複製」，
所以香港那 9 筆名稱差異是**人手核對**後記錄，不是程式抓取。
